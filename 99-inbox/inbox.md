# Inbox

Ce qui n'est pas encore rangé. **À vider, pas à laisser vivre** : une inbox qui
grossit est une deuxième mémoire, non fiable, qui concurrence la première.

Quand une note d'ici est mûre, elle part dans :
- `10-lecons/` si c'est une règle payée par une erreur ;
- `00-methode/` si c'est une façon de faire ;
- `30-modeles/` si c'est un squelette ;
- la fiche du projet concerné si ça ne vaut que pour lui.
