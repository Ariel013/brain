# Modèles

Squelettes à déposer dans un dépôt neuf. `/amorce-projet` les copie et les
adapte ; à la main, il suffit de retirer le frontmatter Obsidian et de remplacer
les `<…>`.

| Modèle | Destination |
|---|---|
| [[modele-claude-md]] | `CLAUDE.md` |
| [[modele-journal-md]] | `JOURNAL.md` |
| [[modele-a-faire-md]] | `A-FAIRE.md` |
| [[modele-adr]] | `docs/decisions/NNNN-<slug>.md` |
| [[modele-point-avancement]] | une entrée de `docs/points-avancement.md` |
| [[modele-backlog]] | une tâche de `docs/roadmap-backlog.md` |

> Un modèle qui n'a servi à rien sur deux projets se supprime. Un modèle qu'on
> a dû corriger à la main deux fois se corrige **ici**.

Voir [[amorce-nouveau-projet]] pour l'ordre dans lequel les poser.
